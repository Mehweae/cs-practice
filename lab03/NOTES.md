git log - Выдаёт общую статистику по коммитам,всем коммитам, без построчных изменений
git diff - Выдаёт разницу между указанными коммитами
git show - Выдаёт изменения произведённые в указанном коммите относительно предыдущего

git log -S"def" - Выводит строки, а точнее когда и кем былии введены строки кода содержащие def
git blame - разбирает весь файл и указывает, какая строка была введена каим коммитом

git restore - Возвращает правки из прошлого коммита, для локальной версии файла
git restore --source=... - Возврашает локальную версию файлов к определённому коммиту, но не меняет коммиты
все незаписанные изменения будут удалены

git revert - Создаёт коммит, который отменяет изменения произведённые в ходе проекта (до указанного коммита)
git reset --hard - стирает всю историю до указанного коммита включая все изменения

Ветка существует для разработки и новшеств которые могут негативно повлиять на работу проекта, а тег существует для обозначения стабильной версии проекта
