
Рабочая папка - локльная директория - локальное место хранения рабочих файлов, где и происходят их изменения, локальный хост репозитория, холдер где хранится проект
Индекс - стейдж - место для подготовки и группировки файлов к коммиту
Коммит - сохранение изменений в файлах для определения версий и возможности откатить проект в случае проблем

Git и GitHub:
Git - локальная система контроля версий, которая способна хранить изменения файлов проекта на устройстве и сравнивать версии проекта. А, при помощи GitHub можно хранить проект в облаке и работать над проектом совместно с командой разработчиков, без необходимости подключаться к отдельному, выделенному серверу, при этом сохраняя возможность параллельной работы в отдельных подверсия(ветках), без страха сломать основную версию проекта и без страха сделать продукт неработоспособным
git diff - сравнивает предыдущий коммит и состояние локальной директории (изменения между ними)
git diff --staged - сравнивает изменения между предыдущим коммитом и файлами, которые находятся в индексе
